# Contributing

Thanks for considering a contribution. Please open an issue before a large change so the problem and expected result are clear. Small fixes can go directly to a pull request.

Set up a local environment with `python -m pip install -e ".[test]"`, then run `python -m pytest`. Add a test that demonstrates a bug before changing the implementation. Keep example images synthetic or explicitly licensed for redistribution; do not upload client artwork, internal documents, personal data, or private QR destinations.

The maintainer will review issues and pull requests as time allows. This project is new and does not promise a response time or a particular release schedule.
